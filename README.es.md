# Portfolio Backend 2.0

[English](README.md)

Backend NestJS deprecado de la iteración anterior del portfolio. Se conserva como referencia; el ecosistema actual está enlazado abajo.

## Stack

NestJS · TypeScript · TypeORM · MySQL · JWT.

## Alcance y configuración

Contiene módulos de datos del portfolio, autenticación y contacto. Base de datos, JWT y correo requieren configuración de aplicación; usar valores locales y mantener las credenciales fuera de Git.

## Desarrollo local

Usar un entorno Node.js compatible con package.json y el lockfile de dependencias, cuando exista.

```sh
npm install
npm run start:dev
npm run build
npm test
```
